## What this project does

Grades how far countries carry out the human rights recommendations they
receive, on the UN Human Rights Committee's **A–E** follow-up scale, for two
mechanisms:

* **Universal Periodic Review (UPR)** — the peer review of every UN member
  State. We assess implementation of each country's **3rd-cycle** recommendations
  against the UN and civil-society reports prepared for its **4th-cycle** review.
* **Human Rights Committee follow-up** — the ICCPR treaty body's own A–E
  grading of the ~3 priority recommendations in each country's Concluding
  Observations.

## Key decisions

1. **Grading scale.** Adopted the Human Rights Committee A–E follow-up scale
   (CCPR/C/108/2), not a home-grown status field.

2. **Report format.** Recommendations are grouped by OHCHR theme; collapsed
   paragraph ranges; a short action phrase; an **Evidence:** list quoting each
   source verbatim with the body/organisation named; a reasoned **Assessment:**
   line. (Modelled on a prior "Malawi" example.)

3. **Calibration from the Committee's own practice.** Mined every CCPR follow-up
   report (143 documents, 2010–2026; ~800 graded sub-limbs). Findings in
   `training/CCPR_followup_grading_corpus_analysis.md`: B and C are ~43% each
   (86% of all grades); A ~5%; D and E rare (E rising to ~9% since 2022).

4. **Blind-test correction.** Graded the four countries' HR Committee follow-up
   paragraphs blind, then compared to the Committee's actual grades: 18/24
   exact, and **every miss was one grade too strict** (C where the Committee
   said B). Corrected rule (in the calibration doc): **C** is narrow (pre-existing
   framework, stalled bills, no action); **B** = any concrete on-point measure
   *adopted in the review period*, even if incomplete; **A** = core ask met;
   **E** = new contrary measure or explicit rejection.

5. **Recalibration applied (2026-09-03).** Denmark 4 themes C→B, Namibia 15,
   Paraguay 12; **US unchanged** (its record is genuine inaction + 2025
   regression, correctly C/E). Post-recalibration B share: DNK 68%, NAM 61%,
   PRY 59%; US C 63% / E 35%.

6. **Website.** Static site (no server), data generated by `site/build.py`,
   interactive world choropleth (d3, vendored offline), one page per country.

## How to reproduce the outputs

```bash
python -m countries.denmark.assess      # + namibia, paraguay
python -m scripts.apply_assessment      # United States
python -m scripts.make_report united-states denmark namibia paraguay
python -m scripts.fill_thematic_list united-states denmark namibia paraguay
python site/build.py                    # consolidated DB + site data
python -m pytest -q                     # 13 tests
```
