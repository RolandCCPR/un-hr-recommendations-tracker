# Implementation Tracker — database, world map and website

This folder turns the country assessments in this project into:

1. **a database** — `assessments.db`, a single SQLite file with every graded
   recommendation (open it with [DB Browser for SQLite](https://sqlitebrowser.org/),
   or query it with `sqlite3`);
2. **a world map** — an interactive choropleth on the home page, countries
   shaded by how far they carried out their recommendations;
3. **a website** — a small static site (`public/`) with the map and a page per
   country. No server code, no database server, no build tools.

Everything is generated by one Python script from the assessment databases you
already have.

```
site/
  build.py            <- regenerates everything below from the country DBs
  data/
    hrc_followup.py    <- the Human Rights Committee follow-up gradings (hand-entered)
    iso3166.json       <- country name / code reference
  assessments.db       <- GENERATED: the consolidated database
  public/              <- GENERATED data + the website you deploy
    index.html          world map + overview
    country.html        one country's full record  (country.html?c=USA)
    assets/…            styles, scripts, the map's world outline
    data/…              JSON the pages read (countries.json, USA.json, meta.json, …)
```

## Rebuilding the data

Whenever you re-run a country assessment (e.g. after `python -m countries.namibia.assess`),
regenerate the site data:

```bash
python site/build.py
```

That rewrites `assessments.db` and everything under `public/data/`. Nothing else
in `public/` changes, so your styling and layout are safe.

### Adding a new country

1. Assess it the usual way so it has a database and a filled thematic list.
2. Add its Human Rights Committee follow-up grades to `data/hrc_followup.py`
   (copy an existing block; use the Committee's evaluation document).
3. Add one line to `SLUG_A3` near the top of `build.py`
   (e.g. `"thailand": "THA"`).
4. Run `python site/build.py`. The map picks it up automatically.

## Previewing locally

Browsers block a page from reading local files, so you need a tiny local server
(the site itself needs no server once it's hosted):

```bash
cd site/public
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser.

## Putting it online (free)

The site is just static files in `public/`. Two easy options:

### Option A — Netlify drop (no account setup, 1 minute)

1. Go to <https://app.netlify.com/drop>.
2. Drag the **`public`** folder onto the page.
3. You get a public URL immediately. To update it later, drag the folder again.

### Option B — GitHub Pages (best if this project is on GitHub)

1. Put this project in a GitHub repository.
2. In the repo: **Settings → Pages**.
3. Set **Source** to "Deploy from a branch", branch `main`, folder
   `/site/public` if that option appears; otherwise set the folder to `/docs`
   and rename `site/public` to `docs`, or copy `public/`'s contents to a
   `docs/` folder at the repo root.
4. Save. The site appears at `https://<your-org>.github.io/<repo>/` within a
   minute or two.

If the CCPR Centre wants it on its own domain, both Netlify and GitHub Pages
support adding a custom domain (`Settings → Domains` / `Custom domain`).

## What the grades mean

The map and pages use the Human Rights Committee's A–E scale:

| | | score used for the map |
|---|---|---|
| **A** | largely implemented / action largely satisfactory | 100 |
| **B** | partially implemented / concrete steps taken, more needed | 70 |
| **C** | not implemented / no relevant action | 35 |
| **D** | no information | 15 |
| **E** | contrary measures taken, or recommendation rejected | 0 |

A country's score for a mechanism is the average of its graded items. The
**Universal Periodic Review** gradings are a first-pass assessment for expert
review (built from the UN compilation and stakeholder reports). The **Human
Rights Committee** gradings are the Committee's own, from its follow-up
evaluation documents.

## No internet dependencies

`d3`, the topojson helper and the world map outline are stored in
`public/assets/` — the site works fully offline and behind a firewall. It sets
no cookies and loads nothing from third parties.
